## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/RohitSingh555/RohitSinghPortfolio.git

# Navigate to project directory
cd RohitSinghPortfolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```

Compiles TypeScript and outputs the production bundle to `dist/`.

### Preview Production Build

```bash
npm run preview
```
